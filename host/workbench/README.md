# 网页工作台

`src/core.js`处理PLY、XYZ、ZIP/CRC和2.5D浮雕；`viewer.js`绘制点云；`app.js`组织文件、视频、串口及下载；`index.html`和`style.css`提供界面。

在仓库任意位置运行`python host/workbench/build.py`，仅从本目录源码生成`docs/index.html`，不读取或嵌入点云样本。Python只需标准库。结果包含CSS和JS，没有CDN，可离线打开。

页面默认为空，用户导入文件、串口接收或主动点击“恢复上次会话”后才显示点云。未载入数据时，点云导出和存档按钮保持禁用。旧的用户项目包与浏览器存档仍可手动恢复，不自动读取旧缓存。

输入和导出边界见快速体验。串口CLOUD/1是数据源接入合同，本仓库未提供完整的板级回读实现。摄像头与串口在用户点击后才请求权限。
