开始使用

  1. 连接采集卡

    在电脑Chrome或Edge中打开网页，连接HDMI采集卡，选择对应视频设备。截图与录制保存的是视频画面；视频编码失败时，会明确标注并导出带时间戳的帧序列ZIP。

  2. 载入真实三维数据

    支持PLY、XYZ、CSV、JSON点云以及本网页导出的项目ZIP。页面不包含预置点云；请导入自己的文件，或从兼容的数据源接收。

  3. 观察与导出

    拖动旋转、右键平移、滚轮缩放。导出PLY保存三维坐标与颜色；六视图ZIP只保存观察画面。

  4. 打印辅助

    浮雕STL把当前点云正面深度转为有底板的2.5D模型，缺失位置保留底板，不是完整物体360°模型。

  5. 保留与分享

    公开网址无需登录。下载离线HTML后也能独立打开；导出项目包可把模型与截图交给别人。浏览器会话只保存在当前设备，可点击“恢复上次会话”主动载入；清理浏览器数据会移除它。

网页不会自动打开串口，不烧录板卡。导入文件和接收数据均在本机浏览器处理。

从数据串口接收点云

连接电脑的数据串口，点击接收后将完整PLY载入预览，再导出到电脑。

需要支持CLOUD/1导出的数据源。仓库中的FPGA代表性模块未提供完整CLOUD/1回读接口；连接HDMI采集卡不会得到三维文件。

板端接入协议

网页发送ASCII：CLOUD/1 GET PLY\n。数据源回复：CLOUD/1 PLY 字节数 CRC32十六进制\n，随后发送指定长度的PLY二进制内容。网页核对长度和CRC后才载入。旧固件需增加对应回读接口。

导出打印浮雕

基于整组点云的正面深度生成矩形浮雕，带1.6mm封闭底板。未采到的位置保留底板。

这是2.5D打印辅助，不是完整360°物体模型。优先使用无人工噪声的原始点云。

输入点云的坐标单位不会直接当作打印尺寸；以上尺寸定义输出STL。打印前请导入切片软件核对。
