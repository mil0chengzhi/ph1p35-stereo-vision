# 版本与状态

以下以2026-11-04归档材料为快照，不表示工作区之后的变化已同步。A/B表示逻辑职责，目录名称中的Stereo不必然表示当前模式执行重建。

| --- | --- | --- |
| AM94 / V94_1_Monocular | A单目，配NB91 | 多模式照片与阶段稳定性记录 |

## 与设计范文的关系

理想完成态报告描述目标架构，含示例资源、耗时、有效率及测距误差；不是这些历史版本的实现报告。真实代码的单路径、正交观察及外部距离输入边界，以源码和阶段记录为准。

本发布包只摘取代表性模块，不附表中各版本的完整工程、厂商IP或位流。`fpga/manifest.json`列出具体复制文件及来源。完整工程需要原开发环境、顶层约束与IP生成结果。
