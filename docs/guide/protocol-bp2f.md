# BP2F距离值传输协议

该协议传输用户外部输入的距离值，不在UART模块内估计双目距离。适配BP2F rev100，物理UART为9600bit/s、8N1。

## 请求 8字节

`A5 5A seq op lo hi reserved crc8`

- `seq`为0～255递增序号，上一请求未完成时不追加长队。
- `op`：0x00查询，0x20更新，0x21读取距离，0x22清除有效。
- 更新值为小端毫米整数500～750；例如625mm的lo/hi为0x71/0x02。
- reserved为0；查询和清除的lo/hi也为0。
- CRC8覆盖前7字节，poly0x07、init0、不反射。标准向量ASCII`123456789`结果0xF4。

## 应答 24字节

| 字节 | 内容 |
| --- | --- |
| 0～1 | 5A A5 |
| 2～3 | seq回显、结果码 |
| 4～7 | 协议1、角色2、构建100、能力0x30 |
| 8～10 | 小端毫米值、有效标志 |
| 11 | 状态flags，bit3为距离OSD开启 |
| 12～15 | 请求与已应用观察token |
| 16～19 | 历史模型选择兼容字段；不代表保留预存回放 |
| 20～22 | 错误计数及保留字段 |
| 23 | 前23字节CRC8 |

网页核对长度、帧头、seq、CRC、返回码、版本、角色、能力和距离有效标志。建议每500ms保活，板端长期无更新后置无效。0.1cm为输入和显示步进；并非精度声明。

此协议不同于早期ASCII `D0500\n`，也不同于理想范文中的v2协议。不要混用。仓库只保留距离输入与OSD相关摘选，不提供原有预存双帧按键控制；按键行为与完整集成需以实际装载镜像为准。
