# 多版本RTL与约束归档

此目录来自同一PH1P35工程的`PH1P35_FPGA_RTL`交付包，与仓库中的网页上位机、固件候选和展示资料共同组成工程发布材料。

| 目录 | 保留范围 |
| --- | --- |
| stereo_link_tools | 原交付包中的工具侧RTL与接口模块 |
| V15_2_Stereo | 原版本目录中的RTL、头文件及约束 |
| V45_1_Main | 原版本目录中的RTL、头文件及约束 |
| V63_1_Main | 原版本目录中的RTL、头文件及约束 |
| V75_2_Stereo | 原版本目录中的RTL、头文件及约束 |
| V91_2_Stereo | 原版本目录中的RTL、头文件及约束 |
| V94_1_Monocular | 原版本目录中的RTL、头文件及约束 |
| V94_2_Stereo | 原版本目录中的RTL、头文件及约束 |
| V95_2_Stereo_A | 原版本目录中的RTL、头文件及约束 |
| V96_1_Monocular_HMI | 原版本目录中的RTL、头文件及约束 |

文件按原相对路径和原字节保留，包括原有中文编码、换行及版权注释。不同版本的同名模块不应一起加入同一个综合文件集。原始来源及逐文件SHA-256见[provenance.json](provenance.json)。

厂商`al_ip`目录和加密IP不进入公开归档；具体排除清单记录在校验文件中。本目录也不含完整IDE工程元数据、安装包和可下载位流。需要结合相应版本的工具、板卡、厂商IP及工程配置才能恢复完整构建。本次发布没有重新执行FPGA综合、时序验收或上板测试，版本状态以[工程版本说明](../../docs/guide/versions.md)为准。

未为原有代码新增统一开源许可证，原文件中的署名与版权说明继续保留。
