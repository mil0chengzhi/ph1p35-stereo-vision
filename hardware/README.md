# 硬件连接与边界

平台为两块PH1P35开发板、两路SC520CS相机、二维云台及驱动、HC-05和HDMI显示。可选HDMI采集卡只提供视频输入给电脑。

| B板端 | HC-05端 | 方向 |
| --- | --- | --- |
| M1 TX | RXD | FPGA到模块 |
| L4 RX | TXD | 模块到FPGA |
| GND | GND | 共地 |

BP2F协议使用9600bit/s、8N1，信号电平与GPIO Bank、模块实际载板规范匹配，模块按其额定值供电。SPP无线端口的设置不等于改变模块与FPGA之间的物理UART波特率。

相机调焦、位置或朝向改变后应重新验证标定。双板配对以逻辑角色、固件签名和协议版本判断，不靠目录名或照片中左右摆位判断。原生版本、云台版本和预存版本的按键定义见版本表与对应完整工程，不交叉套用。

厂商原理图、DDR和MIPI加密IP未放入本仓库。不要依据本代码摘选替代完整引脚约束或直接烧录。
