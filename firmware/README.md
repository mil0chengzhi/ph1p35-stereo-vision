# 内置RISC-V服务候选

本目录来自AM96源代码归档中的`shared_ae_awb`。保留AE/AWB、区域滤波与目标事件归约代码，`math_service.c`为联合服务入口，候选startup与链接脚本保持层次。

**原始状态为UNSELECTED。** `ORIGINAL_STATUS.txt`明确说明该联合服务未被选入完整合格镜像，部分邮箱字段是拟议接口，不能把代码存在当作已完成硬核集成。这里不继承完整SDK、时序或实机资格。

源注释提到RV32IM、ILP32及体积优化配方；具体ISA、ABI、内存布局与器件硬核SDK必须由完整工程核对。本仓库没有附工具链或预编译ELF，也不从桌面C编译通过推导板端运行结论。

值得研究的分工：硬核接收像素统计和有序任务，执行低频决策；逐像素算法、行缓存、匹配和显示继续留在RTL。AE优先级、ticket受理、过期事件与目标历史提交可结合原注释阅读。
